# 金甌女中轉學生報名系統 v1

這是可在自己電腦試用的版本。請使用虛構考生資料。

## 啟動

1. 完整解壓縮 ZIP。確認電腦有 Python 3.10 以上版本。
2. 在解壓縮後的 `jinou-transfer-v1` 資料夾開啟終端機。
3. Windows 執行 `py -u app.py`；macOS 或 Linux 執行 `python3 -u app.py`。程式只使用 Python 標準函式庫。
4. 按終端機顯示的網址開啟考生頁與管理後台。每次啟動會在終端機顯示本次管理密碼。若環境變數 `JINOU_ADMIN_PASSWORD` 已設定，使用該設定值登入。
5. 試用結束後按 Ctrl+C 停止。

| 入口 | 網址 |
|---|---|
| 考生報名 | http://127.0.0.1:8000/ |
| 管理後台 | http://127.0.0.1:8000/admin |

若 8000 埠已被使用，先設定環境變數 `JINOU_PORT` 為其他埠號，重新啟動後依終端機顯示的網址開啟。

## 試用流程

- 在考生頁填寫資料，選一個科別與一個年級，手寫簽名及上傳 3 MB 以內的 JPG 或 PNG。頁面開啟時由後端以臺北時間配發 12 碼報名編號。同一秒已有配號時，頁面會短暫重試。
- 送出前可列印預覽，並標示「尚未送出」。送出後可列印同編號的 A4 兩聯表或另存 PDF。學校保存上聯，收款人現場填寫下聯的實收金額與日期並核章，再交考生。
- 後台登入後點「更新名單」，可查詢、修改及刪除報名紀錄，重印同一版兩聯表、列印 A4 橫式面試評分名冊，或下載完整 Excel 報名總表。
- Excel 包含所有文字報名欄位及相片、簽名的完成狀態。影像保存在報名紀錄內，可從後台開啟或列印。
- 試用版用瀏覽器 Cookie 識別考生的同一次報名。重新整理可回到原編號，已送出時可重印。要模擬另一位考生，可使用不同瀏覽器，或清除本機網站 Cookie 後再開啟。尚未送出的欄位內容需重新填寫。
- 系統預設把資料存成同資料夾的 `registrations.sqlite3`。關閉重開後資料仍在。若只想重置虛構測試資料，先停止程式再移走該測試資料庫。

目前只在本機運行，年級暫列高一、高二。正式對外使用前需確認當期科別與年級、部署 HTTPS、設定正式管理帳號與資料備份。
